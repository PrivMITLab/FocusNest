# Getting Started with FocusNest

1. Install FocusNest and complete the **10-step Onboarding** (all optional permissions can be skipped and enabled later).
2. Grant **Usage Access** (`PACKAGE_USAGE_STATS`) when prompted so FocusNest can read real daily screen time and app opening counts via `UsageStatsManager`.
3. Enable the optional **Accessibility Service** if you want real-time app blocking and configurable Reels/Shorts pause screens.
4. Set your daily screen-time and focus goals, flag distracting apps, and start your first Pomodoro or Countdown session from the **Focus** tab.
